# 献立・買い物

CLAUDE.md から移した仕様（中身は同じ）。この機能を直す時だけ読む。仕様を変えたらここを直す。

## 仕様
- 買うかも：前の週の「買い物」から品名ごとの周期を出し、そろそろの物を先に（今のリストにある物は出さない）
- 献立：GAS の boot は今週の日曜〜来週の土曜（MENU_WEEKS=2）の献立を日付順に返し、menuFrom・menuTo を付ける。ごはんタブの献立は「今週／来週」で週を送れる（state.menuWeek。来週を見る時は見出しの「今週」も「来週」に、日は日曜から）。menuTo の無い古い GAS なら今週だけ（切り替えを出さない）。来週の日も、献立を入れる・直す・材料を送るができる
- 献立の材料を買い物リストへ：押すと「材料を買い物リストへ」のシート（編集シートの kind:'toShop'）を開き、材料ごとに行き先＝買い物リストの分類（今のリストの分類＋boot の shopCats。名前は「（…）」を外して短く出す）か「家にある」を選んで、まとめて addShopMany（品ごとの cat つき）。家にある物は送らない。まだ買っていない同じ品名がリストにある物は「リストにある」で選べない。既定は前回その品を入れた分類（boot の shopLastCat＝献立に出る品だけの「品名→分類」。品名は GAS の normName と同じそろえ方）、分からなければ「店」を含む分類（無ければ最初の分類）。送る時にもう一度リストと突き合わせる。GAS の addShopMany も、その週にまだ買っていない同じ品名と、同じ送りの中の重なりは足さない（added・skipped を返す）
- 買い物の品名の横に、どの献立の材料か（例「火：豚汁」、今日なら「今日：…」、来週なら「来週火：…」、2つ以上は「火・木」「火・来週火・木」）：画面の側で、今日から先の献立（boot の今週・来週）の材料と品名を突き合わせる（NFKC・空白・かっこ書きを外して同じなら）。シートの列は増やさない（献立を直せばすぐ合う・手で足した物や Muse の toShop でも出るため）
- 献立の写真：「写真URL」が空なら、GASが料理名から日本語版ウィキペディアの記事の写真（自由なライセンスの物だけ。Wikimedia Commons）を付ける。記事名がぴったり合う時だけ（かっこを外す→＆などで分ける→「〜の」の後ろ→ DISH_ALIAS の言いかえ）。見つからなければ今までのイメージ写真。結果はスクリプトのプロパティ `dishimg:料理名` に覚える（見つかった物60日・なし7日）。作者・ライセンスも Commons から取り（取れない写真は使わない）、画面には「写真：作者 / ライセンス / Wikimedia Commons」を出して元のページ（とライセンス）へつなぐ（CC BY・BY-SA の表示の条件）。写真URLに書けばそちらが優先
- 献立をアプリから入れる・直す・消す（saveMenu/deleteMenu。日付ごとに1つ。人数の欄があれば「N人分」と出す。材料は1行に「品名 量」→ シートでは「品名:量 / …」）

## 細かい決まり（レビューで直したもの）
- 買い物を手で足す時も、まだ買っていない同じ品名は足さない。過ぎた日（今日より前の日付）の献立には「材料を買い物リストへ」を出さない
- ごはんタブの見出しの「今日：」は、選んだ日ではなく今日の献立
