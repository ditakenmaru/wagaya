# Muse との連携

CLAUDE.md から移した仕様（中身は同じ）。この機能を直す時だけ読む。仕様を変えたらここを直す。

## 仕様
- Muse（MetaのAIエージェント）から書く：action:'muse'＋鍵（メニュー「Muse用の鍵を作る」で人ごとに。シート「_keys」にはハッシュだけ。状態を「止める」で止まる）。できるのは list と足すこと（shop/menu/duty/note/diary/feedback/topic/decision/deadline/outing）と、自分の鍵で24時間以内に足した物の undo だけ。日記・写真・設定・メールは返さない。日記は書くだけできる（diary.add：今日の日付・今の時刻・鍵の持ち主の名前で1件。list・履歴には出さない＝Muse は読めない。「Museの記録」には文字数だけ。1000字で切って cut:true、1日30件まで、日付と時刻は日本時間＝海外では時差の分ずれる。鍵ごとの許可はない。持ち主の希望、2026-11-21）。書いたものは「Museの記録」に残る。Museに渡す説明は muse/README.md（鍵は書かない）。献立の menu.add は toShop:true で材料のうちリストに無い物を買い物へ
- Museに出さない担当：担当シートの列「Museに出さない」（空・FALSE・いいえ・0・no 以外は全部「出さない」＝privMark）。大項目にあれば小項目も。Muse の list の担当と、その担当に付いた申し送りから外す（privDutyIds は担当シート全体から）。boot の dutiesAll は priv＝その行の印、privAny＝大項目から来た分も含む（編集シートは priv だけを読み書き。小項目を保存しても大項目の印を書き込まない）。編集シートの「Museに渡さない」は GAS 18 から（privApi）。吸入・薬は出さない（持ち主が決めた）。予定・期限・相談・自由な申し送りには効かず、それらは隠さない（持ち主の判断：隠すと Muse の結果が悪くなるため。2026-11-21）
- Muse の履歴（op history、読むだけ）：kind＝menu（過去の献立：日付・料理名・材料名）／shopTrend（品ごとの集計：リストに入った週の数・買ったの回数・最後の週・何週ごとか）／dutyBalance（担当ごと・人ごとの済の回数。Museに出さない担当・小項目は数えない）。weeks 1〜8。鍵ごとの「読める履歴」（_keys の列。空＝読めない）で許した種類だけ。1日30回。読んだら「Museの記録」に種類と件数（ロックの中で）。生の履歴・全件・日記・写真・コメント・メールは出さない（持ち主と決めた方針：用途ごとの集計だけ、傾向の当てはめは Claude 側）
- 相談の添付（画像・PDF）はMuseに渡さない（museList は問い・選択肢・期限だけ。「Museに相談」の下書きにも入らない）。写真・日記と同じ扱い
- Museに相談ボタン（相談カード・お出かけカード・献立の見出し・アカウントのシート）：その項目の文だけを下書きにして見せ、本人が直してから「コピーしてMuseを開く」（muse.ai）か「WhatsAppのMuseで開く」（番号は端末の localStorage `museWa`。wa.me の text に入れる）。アプリから自動では送らない。写真・日記・メール・他の項目は入れない。入力の画面（気づき・担当ごとの申し送り・申し送りの一覧の書く欄）の「Museに整えてもらう」（v77、持ち主の希望）：いま書いた文だけを下書きに入れ、誤変換と言いよどみだけ直してアプリに入れてもらう頼みを付ける（日記＝diary.add、申し送り＝note.add。担当に付けた申し送り・代わってほしいの頼みは Muse から入れられないので、整えた文を返してもらって自分で貼る＝polishBack）。送るのは本人（同じシート。museKind・museFrom）。送ったらこちらの下書きは消す（二重に入らない。トーストの「元に戻す」で戻る。コピーできなかった時は消さない）、やめたら入力に戻る。「Museに出さない」担当に付けた文にはボタンを出さない（polishHidden）。下書きの説明に「Meta 側に残ることがある」と書く。`python3 tests/ui_muse_polish.py`
