# 予定・期限・お出かけ

CLAUDE.md から移した仕様（中身は同じ）。この機能を直す時だけ読む。仕様を変えたらここを直す。

## 仕様
- 予定：今日から4週間（GAS の PLAN_DAYS=28。妻の希望で2週間から延ばした、2026-11-21）。カレンダーの上の ‹ ›（持ち主の希望、v79）で4週間ずつ先へ・戻る：先のページは action:'plansMore'（from=そのページの最初の日。読むだけ・ログインが要る・今日から400日まで＝last で › を止める。GAS 19 から）で読み、state.planPages に覚える（base＝boot の plansTo。日が変わった時・引っぱって更新した時は捨てて今日のページへ）。カレンダーも下の一覧もそのページの4週間を出す（state.planPage.n。0＝今日から）。今日より前へは戻らない（‹ は止まる）。先のページでは真ん中に日付の範囲と「今日へ」。一覧の下の「次の4週間へ ›」も同じ動き。タブを移ると今日のページに戻る（App.prototype.setState）。v78 の「その先を一覧の下に足す」形はやめた。カレンダーが読めない時は code calendar で返し、画面は「読み込めませんでした」。Muse の list に出す予定は今までどおり今日から2週間（MUSE_PLAN_DAYS。画面を延ばしても Muse に渡す範囲は広げない）。カレンダーは1回250件までなので続きを3ページまで取る。ホームのカレンダーは2週間ぶんで、ホームにも ‹ › を出して2週間ずつ送る（v80、持ち主の希望。1ページの日数＝planUnit：ホーム14・予定のタブ28。読んだ予定は28日ごとのかたまりで持ち、ホームの2ページ目＝3〜4週目は boot の分から読み込みなしで出す）。ホームの一覧は今日のページだけ3日分にしぼり、先のページではしぼらない。一覧の下の「次の4週間へ ›」は予定のタブだけ。`python3 tests/ui_plan_more.py`。押さなくても見えるように、上は週ごと（7日×4段）のカレンダー（何日も続く予定は帯、1日の予定は2行までの札、+N）、下は予定のある日だけの一覧（続く予定は最初の日に「11/26〜12/3」で1回）。カレンダーの日を押すと一覧のその日へ。ホームでは一覧を3日分にしぼる。GASは続く予定を日ごとに出し key・from・to を付ける（古い画面でも日ごとに出る）。boot に plansFrom・plansTo
- 期限：近い順、済のチェック。お出かけ：行きたい（人1・人2）と行く日。行く日を決めると「予定」シートにも入る（カレンダーIDがある時は入れない）
