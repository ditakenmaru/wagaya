# 今日の流れ・担当

CLAUDE.md から移した仕様（中身は同じ）。この機能を直す時だけ読む。仕様を変えたらここを直す。

## 仕様
- 家を出る時刻：設定「朝の出発時刻」（既定8:00）。今日の流れの見出しの下の「家を出る 8:00（あと25分）変える」から2人とも変えられる（setDepart）。担当の時刻に「出発」「出発-30」と書く（アプリでは「家を出る時刻に合わせる」＋「N分前」）と、出発ちょうど・30分前として動き、出発を変えると一緒にずれる（GAS の dutyTime。boot の duties・dutiesAll に rel、ui.depart）。あと何分は平日の3時間前から
- 今日だけ担当を替える：今日の流れの各行の名札（担当）を押すと「担当を替える」シート（編集シートの kind:'who'）。相手の担当なら「今日は自分がやる」、自分の担当なら「代わってほしいと頼む」（申し送りで頼む）、替えた日は「いつもの担当に戻す」、ほかに「いつもの担当を変える」（くり返しの決まりを開く）。相手に回すのは頼んで「代わる」を押してもらった時だけ（片方で決めない）。GAS：チェックの種類「担当替え」（誰＝代わった人）を swapDuty で書き、boot の duties の who をその人に、orig に元の担当。申し送りの列「依頼」=swap・「依頼の日」・「依頼の答え」（ok/ng）。answerSwap は頼まれた人だけ（代わる＝その日の担当替え＋確認済み）。申し送りの画面からも「今日の担当を代わってほしい」を付けて送れる。別の日（明日から7日先まで、app.js の ASK_DAYS）も前もって頼める：「担当を替える」シートの「別の日を代わってほしい」（その担当の日だけ並べる。返事待ち・代わってもらう日は押せない。断られた日はまた頼める）と、担当の編集シートの「別の日を代わってほしいと頼む」。頼めるのはいつもの担当が自分の物だけ。申し送りの依頼の日にその日を入れる（answerSwap が依頼の日の担当替えを書き、その日が来たら boot が替える。過ぎた日の頼みには答えない＝code past。答えの通知は今日以外なら日付つき）。先の日の担当替えは boot の swapsAhead（明日から SWAP_AHEAD_DAYS=8 日、{date,id,who,orig}）。引き受けてもらった今日・先の日は、いつもの担当の人だけが取り消せる（cancelSwap「やっぱり自分でやる」。2回押し、state.cancelArm。その日の担当を済にした後は断る＝done。取り消すと GAS が相手宛ての申し送りを自動で足し、通知もそこから）：申し送りのカード（答えの横）、「別の日を代わってほしい」の「代わってもらう」の日、今日なら「担当を替える」シート。引き受けた人は一方的に戻せない（片方で決めない）：「戻してもらえる？と頼む」＝同じ日の頼みを元の人へ（askBack。元の人が「代わる」と同じチェック行が元の人で上書きされて戻る。答えの通知は「○○が自分でやります（担当が戻りました）」）。頼み返して返事待ちの間は二度押せない（pendingAsk）。取り消し・戻った頼みは「（いつもの担当）の担当に戻りました」。取り消しと swapsAhead は GAS 16 から（app.js の swapApi。古い GAS では出さない。頼み返しは古い GAS でも動く）。言葉は前向きに（「今日だけ」と書かず「今日の担当」）（今日の自分の担当の時だけ）
- 大項目と小項目（担当）：担当シートの列「親」＝大項目の id。1段だけ（小項目の下には付けない＝bad_parent）。小項目の時刻・担当・曜日は空で、大項目についていく（GAS の linkDutyParents。担当替え・休みも大項目に合わせる。小項目は大項目が出る日だけ出る）。boot の duties・dutiesAll の小項目に parent。画面は小項目を大項目の行の中に字下げで並べ、数・つぎの担当・タイムライン・続けた日数（streakOf）は大項目だけで数える。大項目の済＝小項目が全部済（行も見出しも同じ決まり）。大項目を押すと全部済／全部戻す（setDoneMany）、小項目を全部済にすると大項目も済、1つ外すと戻る。「元に戻す」では前から済だった小項目は済のまま。編集シートで大項目を選ぶ（dutyApi＝GAS 17 から）、大項目の編集に「＋ 小項目を足す」、消すと小項目も消える（deleteDuty）。GAS の saveDuty は parent を送った時だけ「親」を書き換える（古い画面で直しても小項目のまま）。小項目はアプリから足す（シートに手で入れると、id が時刻＋やることから作られて、大項目の時刻を変えた時に外れる）。持ち主はこの形をほかの場面（期限・買い物など）にも使いたい
- 今日の流れの各行の申し送り（吹き出しとバッジ）は今日の分だけ：ふつうの申し送りは今日書いた物と、昨日のその担当の時刻より後に書いてまだ確認していない物（夜に書いた明日の朝の分は朝に出る。確認済みの昨日の物は出さない。時刻のない担当は今日書いた物）、「代わってほしい」は依頼の日が今日の物。前の物は申し送りの一覧で見る。開いたまま日をまたいだら、毎秒の timer が気づいてすぐ読み直す（dayRolling）
- 続けた日数（streak）：担当を全部終えた日が何日続いたか（チェックシートから。担当のない日・休みは飛ばす）。2日以上で見出しに出す

## 細かい決まり（レビューで直したもの）
- 足した担当は、ホームで8件にしぼる時も残す（state.lastDuty）
