# 相談・話題・申し送り・コメント

CLAUDE.md から移した仕様（中身は同じ）。この機能を直す時だけ読む。仕様を変えたらここを直す。

## 仕様
- 話題の優先度：各カードの「優先度を高く」（編集シートでも）で、話題シートの列「優先」=高。高い物は色（--attn）が変わって一番前（GASもその順で返し、画面でも並べ直す）
- 話題は横スライドのカード（Apple Store・Amazon風。持ち主が選んだのは話題だけ）：カードごとに色のグラデーション（TOPIC_TONES、id から決まる。白い文字。中のボタンは半透明の白＝CSS の .tcard）。カードの幅は画面幅−88px（最大320px）で次のカードを少し見せ、scroll-snap で1枚ずつ止まる。ホームでも10件まで並べる（HOME_LIMIT）。チェックや作業のセクション（今日の流れ・買い物・期限・申し送り・相談）は縦のまま
- ふたりで決めることも話題と同じ横スライドのカード（v70、持ち主の希望）：相談ごとに1枚、上の質問の帯は相談ごとの色（TOPIC_TONES、期限は帯の上に小さく）、答える所は白。操作は下の1行（文字は --t-foot）。コメントはふだん畳む（アコーディオン：「コメント N件 ⌄」で開く＝state.decThreadOpen。コメントがある時の「コメントする」は開いてから。書いた後は開いたまま）。補足の文は2行まで。ホームでも10件まで
- リンク集（アーカイブ）：話題シートの「表示」を外した物。話題セクションの下の「リンク集（アーカイブ N件）⌄」で開く（boot の topicsArchived、新しい順に50件）。話題のカード（直す中）や編集シートの「リンク集にしまう」、新しく足す時の「リンク集に入れる（話題には出さない）」、リンク集の「話題に戻す」。saveTopic の show で切り替え
- 「ふたりで」タブ（決めることがあるタブ）の上に申し送りの入口。タブのバッジ＝自分宛ての未確認の申し送り＋相手からの新しい返信＋まだ答えていない相談
- 申し送りの返信：各申し送りの「返信」から、その場で書いて送る（返信シートに 対象「notes:id」）。自分宛てで未確認の物は、返信すると確認済みにもなる。相手の返信は「新しい返信」の印（申し送りを閉じると見たことになる）
- ふたりで決めること（相談）：カードの下にコメント（新しい2件と「コメントをすべて見る」、「コメントする」でその場で書く。長いコメントは3行で切って「さらに見る ⌄」でその場で下に伸ばす。3件目より前のコメントは「前のコメントをさらに見る（N件）⌄」でその場で広げる。各コメントに「返信」＝1段だけの返信。返信シートの「decide:id」と「返信先」＝コメントのid）。詳細の画面でも返信は親コメントの下に並べる。2人がそれぞれ答える。答えがそろった時だけ「決まった」にできる（GASでも確かめる。片方で決定扱いにしない）。決まった相談は一覧から外し、セクションの下の「決まったこと（アーカイブ N件）⌄」でその場に広げる（新しく決まった順。1件ずつ白いカード：左に番号の丸（決まった順で古い=1、新しく決まるほど大きく、ずれない）＋質問（17px、3行まで）→緑の面に小さく「✓ 決まった」と答え（17px太字、「決まった：」の頭は外す）→「詳細を見る」と「相談に戻す」。背景と同じ灰色で溶けて見づらかったため、v83で白いカード、v84で番号と答えの面を追加）。選択肢に「話したい」があっても1つだけ出す
- 長い文は5行で切り、「詳細を見る」（コメントがあれば「詳細を見る（コメントN件）」）で全文とコメント（画面の言葉は世の中のアプリに合わせて 詳細を見る・コメント・送信・削除）（返信シート：id／対象「種類:id」／誰／日時／本文／返信先。addReply/deleteReply は自分の分だけ）。対象は 話題・相談・日記・お出かけ・ニュース・申し送り。ニュースの「詳細を見る」も同じ画面。コメントが付くと相手側に「新着」

## 細かい決まり（レビューで直したもの）
- マイクのボタン（申し送り・気づきの入力、toggleMic）：Web Speech API。iPhone のホーム画面のアプリでは動かない・不安定という報告がある（WebKit の不具合 225298）ので、失敗した時は理由ごとに案内し、キーボードのマイクをすすめる。結果は確定分を順に足す（重なり防止）。起きたことは使われ方に err:mic_理由・act:mic_start（v76）。実機でだめならボタンをやめてキーボードのマイクの案内だけにする案を持ち主と相談
