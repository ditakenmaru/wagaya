# 見た目・ナビ・並び

CLAUDE.md から移した仕様（中身は同じ）。この機能を直す時だけ読む。仕様を変えたらここを直す。

## 仕様
- 最初のタブは「ホーム」（シート上の名前は「今日」）：見える全部のセクションを出し、長い一覧は数件にしぼって「すべて見る」（今日の流れ8・買い物8・期限4・話題10・日記3・お出かけ3・相談10・ニュース5。ホームにあるものはその場で広げ、他はそのタブへ移る）
- ロゴは双葉（1本の芽から2枚の葉＝双子。色は鮮やかなグリーン→ティールのグラデーション #2EE88A→#00C2A0→#0090C8）。ロゴのバー（マーク＋WAGAYA）はどのタブでも一番上に貼りつく。ホームは写真が見出し（写真の上に日付・天気・あいさつ、下に数字の札・人の切り替え・申し送りの入口・並びの帯）。写真を出さない時（人のタブなど）は色の見出し
- 見た目は1つ（Apple風）。見た目a・b・cの切り替えはやめた（localStorage `homeStyle` が残っていても読まない）。デザインの決まりは index.html の先頭の CSS（`:root` の変数）にまとめた：色（--accent-bg が主ボタンの1色。人の色は名札と担当の印だけ。注意 --attn、済み --done）、文字（--t-large 28 / --t-title 20 / --t-body 17 / --t-sub 15 / --t-foot 13 / 最小 --t-cap 12。太さ 400・600・700）、角丸（--r-card・--r-btn・--r-chip・--r-sheet）、余白は8の倍数（細かい所は4と12）。部品はクラス（.btn・.btn-fill・.btn-tint・.btn-gray・.btn-link・.btn-close・.field・.lbl・.seg・.statchip・.tabbar・.appbar・.tabhead）。ダークモードは prefers-color-scheme で変数を差しかえる。人の色はダークでは color-mix で白に寄せる（app.js の inkText・inkTint、--pc-ink・--pc-tint）。献立・買い物の部分の古い inline の色は、CSS の「古い色を決まりに合わせる」段（!important の属性セレクタ）で合わせている（その部分が変数に移ったら消す）
- 上の見出し（ファーストビュー）：時間帯で色とあいさつが変わる（朝・日中・夜・旅行中）。今日の担当の進み・あなたの番・新着・旅行までの日数を出す
- 動き：下のタブの切り替えは View Transitions（app.js の swapView。無い端末・動きを減らす設定ではそのまま）。ホーム以外のタブは大きな見出し（.tabhead h2）がバーの下に隠れると、ロゴの横にタブの名前を出す（html に class "collapsed"。checkTitle）。シートはばねの動き（--ease-sheet、linear() が使える端末だけ）。押した時は小さく縮む（hover:none の端末だけ）
- 右上の名前のボタン（メニュー＝アカウントのシート）は、名前の右にハンバーガーのアイコン。シートの一番上に「移動」（グローバルナビ）：いま見えるセクション（写真・見出しは除く）をタイルで2列に（navTiles。持ち主が選んだ形）。タイルは落ち着いた見た目（持ち主に「うるさい」と言われて直した）：色は青1色、小さな角丸の枠のアイコン（今週のごはんだけ同じ大きさの今日の献立の写真）・名前・中身の一言（hintOf：のこりN件・未確認N件・次の期限・今日の献立・まだ買っていないN品・今日の予定N件 など）の3つだけ。今のタブのタイルは薄い青の背景。「相談・連絡」の頭に「申し送り」（自分宛ての未確認の数のバッジ。相談・期限が見えない時も出す）。押すとシートを閉じて jumpSec（通知の goTo と共通）：タブが変わる時は一気に、同じタブの中は滑らかにスクロール、見出しにフォーカス、0.5秒後にずれていたら合わせ直す。シートは max-height 88vh で中をスクロール、× は sticky。[data-sec] に scroll-margin-top 64px。`python3 tests/ui_menu_nav.py`
- 時刻で並びを変える：朝（設定「朝の並びにする時刻」〜「朝の並びを終える時刻」、既定5:00〜9:00）は「朝の順番」、夜（「夜の並びにする時刻」から）は「夜の順番」。時刻の欄が空ならその並びは使わない。画面の上の帯の「いつもの並びにする」で、その並び（朝・夜・旅行）が終わるまでふだんの並びに戻せる（端末ごと）
- 設定「旅行の期間」（例 2027-08-10〜2027-08-15、8/10～8/15 も可）の間は「旅行中」に印のあるセクションだけ出し、話題を一番上に。「夜の並びにする時刻」から「夜の順番」で並べる
- ホーム以外のタブは、そのタブの主役から決まった順（ふたりで：相談→期限、ごはん：献立→買い物、予定：予定→今週末→話題）。並びは CSS の order で変え、DOM の順は変えない（入れ替えると描き直しで要素が使い回されて属性が崩れる）

## 細かい決まり（レビューで直したもの）
- デザインの見直し（2026-11-21、UIデザイナーの案1〜8）：今日の流れの申し送りはアイコンだけ（文字なし・--label3）、「詳細を見る」は文字のリンク（moreOf）、セクションの見出しの左は20px にそろえる、見出しの右の「直す」は文字のボタン（.btn-link）、申し送りの入口は枠なしで未確認の時だけアイコンを注意の色（notesIconColor）、数字の札で色が付くのは「あなたの番」だけ、期限の最後の行の線は消す（.dlrow）、今日の流れのやることは600・時刻は600で --label2。相談のカードの操作（コメントする・詳細を見る・Museに相談）はカードの一番下の1行の文字のボタンに（v69、持ち主が決めた）。残り（ホーム以外のタブの見出しの重なり、買い物の分類の札）は持ち主と相談してから
- デザインの見直し2（v72）：横スライドの幅は --w-slide（話題・相談・今週末・ニュース共通）、1枚だけの時は全幅。影は --shadow-card（話題だけ）、相談のカードも --shadow-card。相談カードは話題と同じく全面が色のグラデーション（v74、持ち主の希望。v73の薄い色はやめた）：選んだ答えは白（濃い文字＋✓）、ほかの答えは半透明の白に白い文字、答え待ちの文（.dwait）・操作の行も白。答えの横の名札は、ダークモードでも明るい画面と同じ色（--pc-ink 100%。白に寄せた文字が白いボタンの上で読めなくなったため。v75）、選んでいない答えの上では白い札。決まった相談は今までどおり。「すべて見る」は文字のリンク。話題カードの「詳細を見る」は data-more で白い下線リンク。ピックアップニュースのカードも話題と同じ色のカード（.tcard、TOPIC_TONES。v77、持ち主の希望）。今週末のカードを相談カードの形にそろえる案は持ち主と相談してから
- 画面の横はみ出し防止に html・body・#top は overflow-x:clip（ごはんの切り替えの動きは16pxまで）
- コメント・返信の削除は2回押し（1回目で「もう一度で削除」、4秒で戻る）。押す所は44px以上
- 見出しの数字の札は3つまで（減らす順：全部できた日→旅行の日数）。札とタイルは押すと行き先へ（旅行→予定のその日、全部できた日→今日の流れ）
- 写真の見出しに、写真を足す・気づきのボタンを出す（file input はテンプレートの先頭に1つ）
